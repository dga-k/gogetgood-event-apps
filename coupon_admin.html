Coupon Admin

เลือก Excel → แปลงเป็น JSON → บันทึกแยกตาม event → ตรวจรหัสจากหน้าลงทะเบียน

1. เลือกงานและไฟล์ Excel

อ่านทุกชีตและทุกคอลัมน์ ข้ามหัวตาราง เก็บรหัสเป็นข้อความเพื่อรักษาศูนย์นำหน้า รองรับ 6–7 ตัว

2. ตรวจสอบและเก็บ JSON

ยังไม่มีข้อมูล

บันทึกหนึ่งชุดต่อ event หากบันทึกงานเดิมจะใช้ JSON ชุดใหม่แทนชุดเก่า ประวัติการลงทะเบียนยังอยู่

3. ข้อมูลที่ต้องการเก็บเพิ่ม

กำหนดฟิลด์เฉพาะงานนี้ เช่น ชื่อ-นามสกุล หรือสถานที่ ตัวเลือก dropdown คั่นแต่ละตัวเลือกด้วยเครื่องหมายจุลภาค

เลือกงานที่บันทึกไว้ หรือบันทึกชุดรหัสของงานใหม่ก่อน

4. รายการลงทะเบียน

เลือกรายการงานเพื่อดูข้อมูล

Reset จะล้างเฉพาะประวัติการจับรางวัลของงานที่เลือก ไม่ลบข้อมูลลงทะเบียนหรือรหัสคูปอง

5. ผู้ได้รางวัล

เลือกรายการงานเพื่อดูผู้ได้รางวัล

ลบรายคนแล้วรหัสคูปองนั้นจะกลับมาอยู่ในรายการที่สุ่มได้อีกครั้ง
